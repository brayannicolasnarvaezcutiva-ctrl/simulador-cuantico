# ⚛️ Simulador de Laboratorio Cuántico Unificado

Simulador interactivo en Python para la visualización de sistemas cuánticos en 3D, evaluación de campos energéticos y cálculo de probabilidades de transición en tiempo real.

## 🚀 Características
* **Visualización 3D Dinámica:** Tres modos de vista (Malla Continua 3D, Red Monoatómica y Colisionador Dual de Especies).
* **Biblioteca de Fórmulas:** Acceso rápido a impulsos gaussianos, ondas viajeras, osciladores y solitones.
* **Cálculo Físico en Tiempo Real:** Integración numérica de la probabilidad de transición $P_R(t)$ usando SciPy.
* **Portapapeles Integrado:** Botones para copiar y pegar fórmulas personalizadas directamente en la interfaz.
